## PremiumNote 1.1.6 for Windows

Download **PremiumNote-Setup-1.1.6.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Spell check can be turned off
- **Page ⋯ menu → Spell check** switches it on or off for all pages. Your choice is remembered.
- Right-clicking a word with a red underline also offers **Turn off spell check**.
- When it's off, there are no red underlines and the dictionary isn't loaded.
