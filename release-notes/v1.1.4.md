## PremiumNote 1.1.4 for Windows

Download **PremiumNote-Setup-1.1.4.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Diagrams
- **Mermaid in dark mode is easy to read now.** Nodes are raised blue cards with clear borders and light text, lines are light gray, labels sit on readable chips, and notes are amber. Pies, mind maps, timelines, git graphs and journeys use the same vivid colors as charts. Text meets the WCAG AA contrast standard.
- **Big PlantUML diagrams fit the page.** A wide diagram (for example a long sequence diagram) now zooms out to fit instead of being squashed sideways. **Expand** still shows it full size.

### HTML blocks
- **Expand:** open an HTML block in a full window.
  - Choose a page width like a browser's device preview: Fit window, Desktop (1280), Tablet (768) or Mobile (390).
  - Zoom with Ctrl + / − / 0, and scroll long pages.
  - Interactive blocks keep running in the full window. Esc closes it.
