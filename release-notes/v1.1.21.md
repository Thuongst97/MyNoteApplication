## PremiumNote 1.1.21 for Windows

Download **PremiumNote-Setup-1.1.21.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### What's new
- **Slimmer tab bar:** the top bar is 36 px tall instead of 44 px, so pages get more room.
- **New starter content:** the presentation theme starter decks and sample text use neutral examples (product, design, release, growth, launch, migration and AI).
- **Tests:** 37 new automated tests (680 in total); all of them pass.

### Security
The release was checked for known problems in the app's software libraries: none was found.

Also includes everything from 1.1.20.
