## PremiumNote 1.1.1 for Windows

Download **PremiumNote-Setup-1.1.1.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Security
A full security review, with attack tests for common cross-site-scripting tricks:
- **Mermaid diagrams:** diagram text is now cleaned before rendering. Before, HTML event handlers in a shared diagram's labels could briefly reach the page; the app's security policy blocked them, and now they never get there.
- **HTML blocks** can no longer draw outside their own box, so a shared page can't cover the app with a fake screen, such as a fake password prompt. Old-style script tricks in their CSS are removed.
- **PlantUML:** server redirects are limited (at most 3, only to web addresses, no cookies sent).
- **Page icons** only accept plain text.
- **Release builds:** the build pipeline uses pinned, least-privilege steps.

### Fixes and polish
- **Code blocks:** line numbers run down the side again, one per line (they were shown side by side).
- **Code blocks:** the language button has a premium champagne/bronze look (gold in dark mode), the same shape as the Copy button, and a centered label.
- **Page cover:** cancelling the image picker no longer leaves the button stuck on "Uploading…".
