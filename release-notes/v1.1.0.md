## PremiumNote 1.1.0 for Windows

Download **PremiumNote-Setup-1.1.0.exe** below and run it. Your existing notes are kept when you install over an earlier version.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### New in 1.1.0
- **Built-in Automotive library** for whiteboards and drawings (34 editable shapes): Head Unit ECU, modern IVI screen, digital instrument cluster, AVN, HUD, steering wheel, luxury sedan, SUV, EV, 12 V battery, HV battery + BMS, charger, ECU, central gateway, domain / zonal controllers, TCU, CAN, LIN, FlexRay, automotive Ethernet, Android Automotive OS stack, cockpit hypervisor, AUTOSAR, camera, radar, LiDAR, ultrasonic, OBD-II, OTA cloud, key fob, phone projection, speaker/amp.
- **Faster and lighter**, measured on an 800-page workspace:
  - typing in large code blocks is smooth: only the block you edit is re-highlighted;
  - search is instant (about 15 ms instead of up to 400 ms);
  - startup is about 3× faster;
  - memory stays flat while you work.
- **Tab shortcuts work on whiteboards** (Ctrl+T / Ctrl+W / Ctrl+Tab / Ctrl+1…9, Alt+← / →).

### Highlights from 1.0
- Tabs with per-tab back/forward, plus PlantUML (`/puml`), HTML (`/html`) and Markdown blocks.
- Notion blocks: callouts, 2–5 columns, toggle lists and toggle headings, block equations.
- Mermaid diagrams, charts, mind maps, drawings and whiteboards. Diagrams open full-window with zoom and pan.
- Code blocks styled like a code window: file name, language pill, line numbers, Copy.
- Per-page fonts (Default, Serif, Mono, and more), Eisenhower task matrix with reminders, graph view, page export/import.
