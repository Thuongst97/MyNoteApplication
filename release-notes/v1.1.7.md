## PremiumNote 1.1.7 for Windows

Download **PremiumNote-Setup-1.1.7.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Search shortcuts changed
- **Ctrl+Shift+F** searches all pages, whiteboards and presentations. This used to be Ctrl+K.
- **Ctrl+F** finds text in the open tab.

### Find in page (Ctrl+F), like VS Code
- A find bar appears at the top right. Matches highlight as you type, the current match scrolls into view, and a counter shows "3 of 12".
- **Enter / Shift+Enter** (or the ↑ ↓ buttons, or F3 / Shift+F3) move to the next or previous match.
- **Aa** matches case (Alt+C). **ab** matches whole words only (Alt+W).
- Searching starts from your cursor. If text is selected, Ctrl+F searches for it. **Esc** closes the bar.
- In a **presentation** it searches every slide and opens the slide of each match.
- On **whiteboards**, Ctrl+F still uses the whiteboard's own search.
