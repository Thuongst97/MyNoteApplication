## PremiumNote 1.1.12 for Windows

Download **PremiumNote-Setup-1.1.12.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Resizable columns in Markdown tables
- Drag a column's right border in a Markdown table to resize it, and double-click the border to go back to automatic widths.
- The widths are saved with the block and kept when you edit the Markdown.

### Fixes
- **Find (Ctrl+F) now searches inside Markdown blocks.** Matches are highlighted and counted, and next/previous scrolls to them, on pages and slides.
- **Diagram text is no longer cut off.** Labels with bold text or `code` in Mermaid diagrams, including diagrams inside Markdown blocks, now fit inside their boxes.
