## PremiumNote 1.1.11 for Windows

Download **PremiumNote-Setup-1.1.11.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### App identity
- The app's Windows ID is now **premium.note** (it still carried the old project name).
- The installer still recognizes earlier versions, so it upgrades your existing install in place. Your notes, settings and pinned shortcuts are unaffected.
