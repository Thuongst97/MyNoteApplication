## PremiumNote 1.1.19 for Windows

Download **PremiumNote-Setup-1.1.19.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### New: web pages
A new page type where the whole page is one web page, the way a whiteboard is one canvas. Create one with **New web page** in the sidebar, on the New tab screen, or in a page's ••• menu.
- **Edit code** shows the code next to a live preview. It saves automatically.
- Turn **Run JavaScript** and **Internet** on or off. Scripts run in a sandbox and can't reach your notes.
- **Full screen** fills your whole screen. Press **Esc** to come back.
- A web page imported from someone else waits for you to press **Run** before its scripts start.

### Full screen for HTML blocks
The **Expand** view of HTML and Interactive HTML blocks now has a **Full screen** button. The first **Esc** leaves full screen; the second closes the view.

### HTML editors: colours and Format
- The code editors for web pages, HTML blocks and Markdown blocks now show code in colour: tags, attributes, CSS and JavaScript.
- **Format** tidies messy or one-line HTML, CSS and JavaScript into neatly indented code. In the web page editor, **Ctrl+Shift+F** does the same.
