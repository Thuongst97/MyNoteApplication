## PremiumNote 1.1.13 for Windows

Download **PremiumNote-Setup-1.1.13.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Copy images into Jira, Confluence and other web apps
- Select an image and press **Ctrl+C**, or right-click it and choose **Copy image**. The clipboard now holds the picture itself, so web editors such as Jira upload it when you paste.
- Copying text that includes images embeds the images too, instead of copying links that only PremiumNote can open.

### Copy a whole page
Right-click anywhere on a page:
- **Copy page:** rich text with headings, lists, tables, links and images, with diagrams as pictures.
- **Copy page as Markdown**
- **Copy page as plain text**

### Export diagrams as images
Hover over a **Mermaid** or **PlantUML** diagram and use **Export**:
- **Copy as image:** a sharp PNG, ready to paste into Jira, Teams or mail.
- **Save as PNG or SVG…**
