## PremiumNote 1.1.17 for Windows

Download **PremiumNote-Setup-1.1.17.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Illustrated page covers
Page covers aren't limited to colours any more. **Change cover** now has topic tabs with 19 illustrated covers:
- **Nature:** mountains at dawn, pine forest, ocean, desert dunes, cherry blossom.
- **Books:** bookshelf, open book, notebook.
- **Technology:** circuit board, network, code, neon grid.
- **Space:** Milky Way, ringed planet.
- **City:** city at dusk, city at night.
- **Abstract:** waves, geometric, bokeh.

The colour gallery is still under **Colors**. **Add cover** now picks a random illustration. The covers are built into the app, so they work offline and stay sharp at any window size.
