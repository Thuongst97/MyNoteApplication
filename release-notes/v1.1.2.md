## PremiumNote 1.1.2 for Windows

Download **PremiumNote-Setup-1.1.2.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Tasks
- **Easier on the eyes in light mode:** every label, note, due date, count and button now meets the WCAG AA contrast standard (at least 4.5:1; several were around 2–3:1). Due-soon dates are deep bronze and overdue dates deep red. Tasks are white cards on a softly tinted group, and each group has a clear border and header divider.
- **Background color per group:** the paint-bucket button in each group's header picks Default, White, or a **Windows Sticky Notes** color (Yellow, Green, Pink, Purple, Blue, Gray, Charcoal). A sticky color makes the group look like a sticky note, with a deeper band on top and paper below.
- The "Focus" label above the heading is gone.

### Code blocks
- The language and Copy buttons are smaller and more refined.
