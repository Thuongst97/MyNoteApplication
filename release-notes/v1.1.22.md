## PremiumNote 1.1.22 for Windows

Download **PremiumNote-Setup-1.1.22.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### What's new
- **Easier-to-read code in Markdown:** code text inside Markdown blocks (like `npm install`) is now dark blue with no shaded background, instead of red on grey. In dark mode it is light blue.

### Security
The release was checked for known problems in the app's software libraries: none was found.

Also includes everything from 1.1.21, including the slimmer tab bar.
