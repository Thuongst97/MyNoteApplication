## PremiumNote 1.1.5 for Windows

Download **PremiumNote-Setup-1.1.5.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Code blocks: click to select, like VS Code
- **Double-click** selects the word: `max_speed`, `$vehicle` and `getSpeed` are selected whole, with no trailing space. Double-clicking spaces or symbols selects that run.
- **Triple-click** selects the whole line, including its line break.
- **Four clicks** select all the code in the block.
