## PremiumNote 1.1.9 for Windows

Download **PremiumNote-Setup-1.1.9.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Slide master
- **Edit master** puts your logo, a watermark or a background on every slide at once, like in PowerPoint.
- Choose whether the master also shows on title slides, and hide it on any single slide.

### Editable footer
- Click the footer on a slide to edit its text directly.
- New **ALL CAPS** option for the footer.

### Fixes
- Pages: only one "Write something…" prompt shows now, instead of several on empty lines.
- Tables: only one table toolbar shows at a time.
- Slides: resizing the text area no longer shrinks the text.
- Slides: the Insert menu is wider, so long names such as "Mermaid diagram" fit on one line.
- Slides: the toolbar fits smaller windows without pushing the slide list off screen.
