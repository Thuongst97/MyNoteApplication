## PremiumNote 1.1.20 for Windows

Download **PremiumNote-Setup-1.1.20.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Security update
A security review of every feature added since version 1.1.8, plus a check of all the app's software libraries for known problems:
- **Libraries:** none of the libraries inside the app has a known security problem. The tool that builds the installer used an outdated helper library with a known weakness, which is now updated.
- **Saving diagrams as SVG:** scripts and other active content are removed from the saved file. A diagram from a PlantUML server you don't control can no longer carry code into an SVG file that you might later open in a browser.
- **Moving pages:** the app now refuses to move a page inside itself or one of its own sub-pages at every level, not just in the sidebar, so pages can't disappear from the list.

Also includes everything from 1.1.19: web pages, full screen for HTML, and code colours with Format in the HTML editors.
