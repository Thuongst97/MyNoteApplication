## PremiumNote 1.1.16 for Windows

Download **PremiumNote-Setup-1.1.16.exe** below (under *Assets*) and run it. Installing over an earlier version keeps all your notes.

> **First run on Windows:** the installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

### Drag pages to reorganise them
Click, hold and drag a page in the sidebar:
- Drop it on the **middle** of another page to make it a **sub-page**. Collapsed pages open while you hover over them.
- Drop it on the **top or bottom edge** of a page to place it **before or after** that page.
- Drop it on the **empty space** below the list to make it a **top-level** page.

Sub-pages move with their page. A page can't be dropped into its own sub-pages.

### A cleaner sidebar
- Page names use the full width of the sidebar. The ••• and + buttons appear only when you hover over a page.
- Long names fade out softly instead of ending in "…".
- Sidebar text, icons and labels are darker and easier to read.

### Mac
- Downloads now say which Mac they're for: **…-mac-arm64** for Apple Silicon (M1–M4) and **…-mac-x64** for Intel.
- If the Intel version is running on an Apple Silicon Mac, which is much slower, PremiumNote shows a warning and tells you which file to install instead.
